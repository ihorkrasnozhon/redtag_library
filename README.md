## Overview
A library system built on **Salesforce Experience Cloud** for external community users.

**URL:** orgfarm-c01f539399-dev-ed.develop.my.site.com/library

## Technical Stack

* **Hosting:** Experience Cloud.
* **Front-end:** **LWC**.
* **Back-end:** **Apex Controller**
* **Security:** Configured via **OWD** and **Sharing Rules**.
